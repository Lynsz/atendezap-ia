Minor release

## Melhorias

- Analise pos-escala cautelosa criada com decisao conservadora.
- Plano da versao 1.1 criado para consolidar estabilidade sem ampliar escopo.
- Admin de campanhas revisado com resumo pos-escala agregado.

## Correcoes

- Sem correcoes de codigo criticas registradas nesta etapa.
- Correcoes P0/P1 devem ser adicionadas quando houver evidencia real.

- Checklist de release 1.1 criado.
- Matriz de decisao pos-escala criada.
