# Campanha Pos-1.2 - AtendeZap IA

## Objetivo

Rodar campanha pequena apos validar a versao 1.2.

## Condicoes para ativar

- versao 1.2 validada
- sem bugs P0/P1
- checkout funcionando
- IA funcionando
- tracking confiavel
- custo da IA controlado
- suporte preparado
