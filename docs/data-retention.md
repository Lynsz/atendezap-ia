# Retencao de Dados - AtendeZap IA

## Dados armazenados
- cadastro
- onboarding
- historico de respostas
- respostas salvas
- feedbacks
- leads
- assinatura
- eventos internos

## Principios
- armazenar apenas o necessario
- nao registrar secrets
- nao registrar dados de pagamento sensiveis
- nao enviar conteudo sensivel para analytics
- permitir limpeza futura de dados do usuario

## Futuras melhorias
- exportacao de dados do usuario
- exclusao de conta
- anonimizacao de eventos
- politica de retencao automatica
