# Critérios de Decisão — Campanha Pequena Pós-1.1

## Continuar

* nenhum P0 aberto
* fluxo principal funcionando
* custo OpenAI controlado
* suporte controlado
* feedback aceitável
* tracking conferido sem dados sensíveis

## Pausar

* erro 500 recorrente
* IA falhando para múltiplos usuários
* cadastro/login quebrado
* checkout quebrado
* webhook quebrado
* admin exposto
* vazamento de dados ou secret
* custo anormal

## Corrigir e repetir

* usuários chegam mas não concluem onboarding
* usuários geram resposta mas não copiam/salvam
* pricing gera confusão
* feedback indica resposta genérica
* suporte recebe dúvidas repetidas

## Preparar próxima etapa

* ativação aceitável com base explicitada
* respostas consideradas úteis
* cópia/salvamento usados
* interesse em assinatura
* nenhum P0
* P1 controlados
* checkout e webhook estáveis
* custo OpenAI medido e aceitável

## Regra de evidência

* Ausência de métrica não conta como sucesso.
* Não comparar canais sem o mesmo período e definição.
* Não escalar orçamento com amostra insuficiente ou tracking incompleto.
