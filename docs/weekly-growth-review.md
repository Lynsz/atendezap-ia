# Revisão semanal de crescimento

Use uma vez por semana enquanto o produto estiver em produção controlada ou com anúncios pequenos.

## Checklist semanal

- [ ] Quantos visitantes chegaram?
- [ ] Quantos leads foram gerados?
- [ ] Qual campanha trouxe mais lead?
- [ ] Quantos leads viraram cadastro?
- [ ] Quantos usuários concluíram onboarding?
- [ ] Quantos geraram primeira resposta?
- [ ] Quantos iniciaram checkout?
- [ ] Quantos assinaram?
- [ ] Quais feedbacks apareceram mais?
- [ ] Houve bugs críticos?
- [ ] Qual foi o maior gargalo?
- [ ] Qual melhoria será feita primeiro?
- [ ] O anúncio deve continuar, pausar ou mudar?
