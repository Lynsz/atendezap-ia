# Matriz de Decisao - Campanha Otimizada

## Manter campanha se:

- ha leads consistentes
- ha cadastros
- usuarios concluem onboarding
- usuarios geram primeira resposta
- custo esta controlado
- nao ha bugs P0/P1
- suporte esta sob controle

## Ajustar campanha se:

- visitantes nao clicam
- cliques nao viram leads
- leads nao viram cadastros
- cadastros nao ativam
- usuarios usam mas nao chegam ao checkout
- feedback indica confusao de copy

## Pausar campanha se:

- checkout falha
- webhook falha
- IA falha
- custo de IA sobe sem ativacao
- suporte recebe bug critico
- tracking esta quebrado
- pagina de destino nao funciona no mobile

## Escalar com cautela se:

- tracking confiavel
- usuarios ativam
- checkout funciona
- ha sinal real de intencao de compra
- custo controlado
- sem bugs criticos
- campanha pequena mostrou sinal positivo

- Sem dados suficientes.
