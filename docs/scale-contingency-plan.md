# Plano de Contingencia da Escala - AtendeZap IA

## Se custo da IA subir

- reduzir ou pausar campanha
- revisar demo publica
- revisar rate limit
- revisar modelo
- revisar limites por plano
- verificar abuso

## Se checkout falhar

- pausar campanha
- verificar Stripe
- verificar webhook
- revisar logs
- testar staging
- registrar incidente

## Se usuarios nao ativarem

- revisar onboarding
- revisar dashboard inicial
- revisar exemplos
- revisar CTA pos-cadastro
- revisar pagina de destino

## Se suporte aumentar

- identificar tema recorrente
- criar insight
- corrigir FAQ/copy
- corrigir bug, se houver
- pausar campanha se for critico

## Se tracking quebrar

- pausar aumento de orcamento
- validar UTMs
- validar eventos principais
- conferir admin de campanhas
- corrigir antes de repetir campanha

## Se houver bug P0/P1

- pausar campanha
- registrar incidente
- corrigir e validar em staging
- rodar smoke test
- reabrir campanha somente depois de checklist verde
