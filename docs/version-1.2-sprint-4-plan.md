# Versao 1.2 - Sprint 4

## Objetivo

Fechar a versao 1.2 com QA final, documentacao, validacao operacional e preparacao de release.

## Foco da sprint

- QA manual
- seguranca
- billing
- IA e limites
- suporte
- privacidade
- paginas publicas
- tracking
- documentacao
- release notes
- changelog
- checklist de producao

## Fora do escopo

- integracao direta com WhatsApp
- CRM completo
- automacoes avancadas
- multiplos atendentes
- app mobile
- novas funcionalidades grandes

## Criterio de sucesso

- npm run validate passando
- sem bugs P0 conhecidos
- sem bugs P1 graves conhecidos
- fluxos principais validados
- release notes finalizadas
- changelog atualizado
- auditoria atualizada
- versao 1.2 pronta para deploy controlado

## Pendencias herdadas das Sprints 1-3

- Validar Stripe Checkout, Customer Portal, webhook, assinatura ativa, pagamento falho e cancelamento em staging/producao.
- Validar Supabase RLS com dois usuarios reais no ambiente final.
- Validar OpenAI, Resend, tracking, admin e health check no ambiente final.
- Fazer smoke visual real em mobile/tablet/desktop antes de campanha.
- Confirmar dados reais de ativacao, retorno em 7 dias, conversao e suporte antes de qualquer escala.
