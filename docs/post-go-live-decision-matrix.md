# Matriz de Decisao Pos-Go-Live - AtendeZap IA

## Continuar operacao

Continuar se:

- sem bugs P0
- sem bugs P1 graves
- geracao de IA funcionando
- checkout funcionando
- webhook funcionando
- usuarios gerando primeira resposta
- suporte sob controle
- custo da IA controlado

## Pausar campanhas

Pausar se:

- checkout falhar
- webhook falhar
- IA falhar para multiplos usuarios
- tracking principal quebrar
- usuarios nao conseguirem ativar
- custo subir sem conversao
- suporte indicar bug critico

## Corrigir antes de nova campanha

Corrigir se:

- onboarding confuso
- dashboard inicial fraco
- pricing confuso
- pagina por nicho com baixa clareza
- demo sem conversao
- suporte recebendo duvidas repetidas

## Escalar com cautela

Escalar somente se:

- tracking confiavel
- fluxo principal estavel
- usuarios ativando
- checkouts ou assinaturas acontecendo
- custo controlado
- sem bugs P0/P1
- campanha pequena trouxe sinal positivo
