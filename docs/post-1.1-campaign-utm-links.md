# UTMs — Campanha Pequena Pós-1.1

## Padrão

Usar:

* `utm_source`
* `utm_medium`
* `utm_campaign`
* `utm_content`

Campanha:

`post_1_1_small_campaign`

## Exemplos

Manual WhatsApp:

`/?utm_source=whatsapp&utm_medium=manual&utm_campaign=post_1_1_small_campaign&utm_content=invite_short`

LinkedIn:

`/?utm_source=linkedin&utm_medium=organic&utm_campaign=post_1_1_small_campaign&utm_content=post_01`

Instagram:

`/?utm_source=instagram&utm_medium=organic&utm_campaign=post_1_1_small_campaign&utm_content=story_01`

Tráfego pago pequeno:

`/?utm_source=meta&utm_medium=paid&utm_campaign=post_1_1_small_campaign&utm_content=ad_01`

## Regras

* não usar UTM com dados pessoais
* não colocar e-mail ou telefone em UTM
* não colocar nome de usuário em UTM
* usar valores curtos, categóricos e sem texto livre de cliente
* não reutilizar esta campanha para uma rodada diferente
