# Roteiro de Entrevista com Usuários - AtendeZap IA

## Objetivo

Entender se o usuário compreende o produto, consegue gerar valor e por que continuaria ou cancelaria.

## Perguntas

1. O que você esperava que o AtendeZap IA fizesse?
2. Você entendeu que ele gera respostas para copiar, ajustar e enviar?
3. Qual foi a primeira coisa que tentou fazer?
4. Teve alguma dificuldade no onboarding?
5. A primeira resposta gerada foi útil?
6. Você copiaria essa resposta para um cliente real?
7. O que faltou para você usar mais?
8. O preço fez sentido?
9. O que faria você assinar?
10. O que faria você cancelar?

## Como registrar

- não registrar dados sensíveis
- resumir o aprendizado
- transformar em insight
- classificar impacto
