# Versionamento - AtendeZap IA

## Padrão

Usar versionamento simples inspirado em SemVer:

- patch: correções pequenas
- minor: melhorias e funcionalidades compatíveis
- major: mudanças grandes ou incompatíveis

## Exemplos

### Patch

- corrigir bug de layout
- corrigir texto
- corrigir validação
- corrigir erro em API

### Minor

- nova página por nicho
- novo relatório admin
- nova biblioteca de templates
- melhoria de ativação

### Major

- integração direta com WhatsApp
- CRM completo
- mudança grande no modelo de billing
- mudança estrutural no banco
