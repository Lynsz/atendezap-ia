# Fluxo de Suporte — AtendeZap IA

## Objetivo
Organizar como usuários podem pedir ajuda e como solicitações devem ser tratadas.

## Tipos de solicitação
- dúvida sobre uso
- problema com login
- problema com geração de resposta
- problema com assinatura
- problema com checkout
- problema com cobrança
- solicitação de cancelamento
- sugestão de melhoria
- bug

## Prioridades
### Alta
- checkout quebrado
- plano pago não liberado
- usuário não consegue acessar conta
- erro na geração de respostas

### Média
- dúvida sobre planos
- problema em página específica
- dificuldade com onboarding
- erro em resposta salva

### Baixa
- sugestão
- melhoria visual
- dúvida geral

## Processo
- usuário envia solicitação
- solicitação fica como pending
- admin analisa
- admin marca como in_progress
- admin resolve ou rejeita
- solicitação fica registrada
