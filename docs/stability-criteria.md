# Criterios de Estabilidade

## Estavel para operar

- Build passando.
- Testes passando.
- Checkout funcionando.
- Webhook funcionando.
- Geracao de IA funcionando.
- Leads salvando.
- E-mails enviando ou falhando sem quebrar.
- Admin acessivel.
- Sem bugs P0.
- Sem vazamento de dados.

## Nao estavel

- Erro em cadastro/login.
- Erro em checkout.
- Webhook quebrado.
- IA indisponivel sem fallback/mensagem.
- Dados entre usuarios expostos.
- Admin acessivel para usuario comum.
- Build quebrado.

## Regra operacional

Se qualquer criterio de "nao estavel" aparecer, pausar novos convites, campanhas e aumento de orcamento ate corrigir e validar novamente.
