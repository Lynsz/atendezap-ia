# Feedback dos primeiros usuarios

Use este roteiro com 3 a 5 pessoas antes de iniciar anuncios. O objetivo e descobrir se elas entendem o produto, conseguem usar sozinhas e percebem valor no AtendeZap IA.

## Como conduzir

- Envie o link do ambiente controlado e peca para a pessoa tentar usar sem explicacao previa.
- Observe onde ela trava, mas evite guiar antes de ela tentar.
- Peça para enviar qualquer problema em `/feedback`.
- Registre bugs e duvidas no admin em "Feedbacks recentes".
- Corrija apenas problemas que impedem uso, confundem compra ou prejudicam a primeira resposta gerada.

## Perguntas para fazer aos primeiros usuarios

- Voce entendeu o que o AtendeZap IA faz?
- Conseguiu criar conta sem dificuldade?
- O onboarding ficou claro?
- A IA gerou respostas uteis?
- Voce usaria isso no seu atendimento?
- O preco ficou claro?
- Teve alguma parte confusa?
- O que quase fez voce desistir?
- O que voce melhoraria?

## O que observar

- Se a pessoa entende a landing.
- Se consegue usar sem ajuda.
- Se entende os planos.
- Se consegue gerar resposta.
- Se entende o limite mensal.
- Se entende como cancelar.
- Se reclama da qualidade da resposta.
- Se entende que a IA nao envia mensagem direto no WhatsApp.
- Se encontra o canal de feedback quando precisa reportar algo.

## Metricas para acompanhar durante os testes

- Leads capturados no periodo.
- Taxa lead -> cadastro.
- Taxa cadastro -> onboarding concluido.
- Taxa onboarding -> primeira resposta.
- Usuarios ativados.
- Respostas geradas nos ultimos 7 dias.
- Feedbacks de dificuldade de uso.
- Feedbacks nao resolvidos.
- Checkouts iniciados.
- Assinaturas ativas.

## Referencias iniciais de validacao

Estas metas nao sao promessa nem criterio absoluto; servem como referencia para decidir se vale convidar mais pessoas.

- 70% dos usuarios convidados conseguem criar conta.
- 60% concluem onboarding.
- 50% geram pelo menos uma resposta.
- Menos de 30% relatam dificuldade grave.
- Pelo menos 1 pessoa demonstra intencao real de pagar.

## Sinais para pausar liberacao

- Mais de uma pessoa nao consegue criar conta.
- Pagamento ou webhook falha em teste real.
- Usuários nao conseguem concluir onboarding.
- A primeira resposta gerada fica inutil para o contexto informado.
- As pessoas acham que o produto envia mensagens automaticamente pelo WhatsApp.
- O suporte recebe duvidas repetidas sobre o mesmo ponto critico.
