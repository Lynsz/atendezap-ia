# Checklist de Manutencao Semanal

Use este checklist uma vez por semana e tambem depois de campanhas pequenas.

- [ ] Verificar logs Vercel.
- [ ] Verificar erros Supabase.
- [ ] Verificar eventos Stripe.
- [ ] Verificar falhas Resend.
- [ ] Verificar uso OpenAI.
- [ ] Verificar leads.
- [ ] Verificar cadastros.
- [ ] Verificar assinaturas.
- [ ] Verificar feedbacks.
- [ ] Revisar bugs P0/P1.
- [ ] Revisar custos.
- [ ] Revisar tracking.
- [ ] Revisar anuncios, se ativos.

## Saida esperada

- Registrar bugs P0/P1 em `docs/launch-bugs.md`.
- Registrar aprendizados de campanha nos documentos de campanha correspondentes.
- Corrigir primeiro falhas de checkout, webhook, cadastro, IA, e-mail, admin ou vazamento de dados.
- Nao aumentar orcamento de campanha se houver instabilidade tecnica ou metricas sem confiabilidade.
