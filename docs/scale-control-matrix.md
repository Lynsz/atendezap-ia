# Matriz de Controle de Escala - AtendeZap IA

## Pode aumentar orcamento se:

- campanha gera leads consistentes
- usuarios criam conta
- usuarios concluem onboarding
- usuarios geram primeira resposta
- checkout funciona
- webhook funciona
- custo da IA esta controlado
- suporte nao recebe bugs criticos
- nao ha bugs P0/P1
- tracking esta confiavel

## Manter orcamento se:

- ha sinal positivo, mas dados ainda sao poucos
- custo por lead esta aceitavel
- usuarios ativam parcialmente
- ainda ha gargalos corrigiveis
- nao ha bug critico

## Reduzir orcamento se:

- custo sobe sem cadastros
- cadastros nao ativam
- usuarios nao geram primeira resposta
- suporte aumenta
- feedback indica confusao
- custo da IA cresce sem conversao

## Pausar imediatamente se:

- checkout quebrar
- webhook falhar
- IA falhar
- login/cadastro quebrar
- dados de usuarios forem expostos
- admin ficar acessivel indevidamente
- tracking principal quebrar
- custo da IA subir de forma anormal

## Decisao atual

- Nao aumentar orcamento.
- Status: Sem dados suficientes.
- Proxima acao: manter baixo orcamento ate haver ativacao, primeira resposta e sinal de checkout/assinatura sem instabilidade.
