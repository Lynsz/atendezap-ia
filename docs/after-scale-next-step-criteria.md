# Criterios para Proxima Etapa Apos Escala - AtendeZap IA

## Continuar escala cautelosa

- campanha estavel
- usuarios ativando
- custo controlado
- checkout funcionando
- suporte controlado

## Voltar para campanha pequena

- dados insuficientes
- ativacao parcial
- custo instavel
- funil com gargalo corrigivel

## Pausar para correcao

- bug P0/P1
- checkout/webhook instavel
- IA instavel
- suporte critico
- tracking quebrado

## Planejar nova sprint

- feedbacks recorrentes
- churn por motivo claro
- gargalo de onboarding
- baixa percepcao de valor
- copy confusa

## Decisao atual

- Voltar para campanha pequena ate haver dados suficientes para escala cautelosa.

Use `docs/cautious-scale-analysis.md`, `docs/scale-health-diagnosis.md`, `docs/post-scale-decision-matrix.md`, `docs/post-scale-adjustment-plan.md` e `docs/operational-stability-report.md` antes de decidir a proxima etapa.
