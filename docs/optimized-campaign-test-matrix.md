## Regras

- Nao comparar variacoes com menos dados que o minimo operacional.
- Se todas tiverem `Sem dados suficientes`, manter orcamento baixo ou pausar.
- Se uma variacao tiver clique mas nao tiver ativacao, revisar mensagem e rota antes de aumentar verba.
- Se uma variacao gerar cadastro e primeira resposta sem erro, repetir com pequena melhoria antes de escalar.
