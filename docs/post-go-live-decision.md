# Decisao Pos-Go-Live - AtendeZap IA

## Apos 72 horas

Classificar:

- manter campanha pequena
- pausar para correcao
- ajustar funil
- ajustar copy
- ajustar nicho
- corrigir billing
- corrigir IA
- liberar nova campanha
- escalar com cautela

## Criterios para continuar

- sem bugs P0
- sem bugs P1 graves
- usuarios geram primeira resposta
- tracking confiavel
- custo da IA controlado
- checkout funcionando
- suporte sob controle

## Criterios para pausar

- bug critico
- usuarios nao ativam
- custo alto sem sinal
- checkout falhando
- suporte recorrente
- feedback indica confusao grave
