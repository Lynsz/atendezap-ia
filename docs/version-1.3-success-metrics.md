# Metricas de Sucesso - Versao 1.3

## Ativacao

- mais usuarios concluem onboarding
- mais usuarios geram primeira resposta
- mais usuarios copiam resposta
- mais usuarios salvam resposta

## Retencao

- mais usuarios retornam em 7 dias
- mais usuarios reutilizam respostas salvas
- mais usuarios usam favoritos
- mais usuarios usam templates novamente

## Conversao

- mais usuarios visitam pricing apos ativacao
- mais usuarios iniciam checkout
- mais usuarios concluem assinatura
- menos abandono entre primeira resposta e plano

## IA

- menos falhas de geracao
- respostas mais uteis
- menos feedback negativo
- custo controlado

## Suporte

- menos duvidas repetitivas
- menos bugs criticos
- mais clareza sobre o que o produto faz

## Campanhas

- campanha com tracking confiavel
- sinais de nicho mais claros
- custo sob controle
- sem escala prematura

## Prontidao operacional

- Stripe, Supabase RLS, OpenAI, Resend, tracking, admin e health check validados em staging/producao
- sem P0/P1 aberto antes de campanha
- relatorios preenchidos com dados agregados reais ou `Sem dados suficientes`
