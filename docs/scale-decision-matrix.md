# Matriz de Decisao para Escala - AtendeZap IA

## Pode escalar com cautela se:

- tracking esta confiavel
- nao ha bugs P0
- nao ha bugs P1 graves
- checkout funciona
- webhook funciona
- usuarios concluem onboarding
- usuarios geram primeira resposta
- ha checkouts iniciados ou assinaturas
- custo por lead e aceitavel para teste
- feedbacks sao corrigiveis

## Nao escalar ainda se:

- leads nao viram cadastro
- usuarios nao concluem onboarding
- ninguem gera primeira resposta
- checkout nao inicia
- assinatura nao libera plano
- custo sobe sem sinal de interesse
- feedback mostra que o produto nao foi entendido
- bugs criticos continuam aparecendo

## Pausar imediatamente se:

- erro 500 em pagina principal
- cadastro quebrado
- IA quebrada
- checkout quebrado
- webhook quebrado
- dados expostos
- tracking indisponivel

## Como usar

- Se qualquer item de pausa aparecer, pausar anuncios antes de testar novas copies.
- Se a campanha tem leads mas nao tem ativacao, corrigir funil antes de aumentar orcamento.
- Se ha ativacao e checkout sem P0/P1, aumentar apenas de forma gradual e revisar diariamente.
