# Matriz de Incidentes Pos-MVP - AtendeZap IA

## P0 - Pausar operacao

* cadastro quebrado
* login quebrado
* onboarding quebrado
* dashboard quebrado
* IA indisponivel para multiplos usuarios
* resposta nao salva
* checkout quebrado
* webhook quebrado
* admin acessivel para usuario comum
* vazamento de dados
* vazamento de secret
* custo OpenAI anormal
* erro 500 recorrente em rota critica

## P1 - Corrigir rapidamente

* botao principal morto
* erro tecnico bruto para usuario
* mobile inutilizavel
* resposta da IA ruim ou perigosa
* limite mensal inconsistente
* feedback quebrado
* suporte quebrado
* pricing confuso
* RLS bloqueando proprio usuario

## P2 - Planejar

* ajuste visual
* melhoria de texto
* melhoria de template
* melhoria de admin
* melhoria de relatorio
* melhoria de onboarding

## Processo

1. Registrar incidente.
2. Classificar severidade.
3. Corrigir em branch segura.
4. Rodar validacoes.
5. Fazer deploy preview.
6. Rodar smoke test reduzido.
7. Promover correcao.
8. Atualizar relatorio.
