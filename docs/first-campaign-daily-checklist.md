# Checklist Diario da Primeira Campanha - AtendeZap IA

Use este checklist uma vez por dia enquanto a campanha pequena estiver ativa. Registre decisoes no relatorio da campanha.

## Anuncios

- [ ] verificar gasto
- [ ] verificar alcance
- [ ] verificar cliques
- [ ] verificar CTR
- [ ] verificar custo por clique
- [ ] verificar comentarios ou mensagens
- [ ] verificar se o link usa UTMs corretas

## Site

- [ ] verificar visitas
- [ ] verificar paginas mais acessadas
- [ ] verificar UTMs
- [ ] verificar erros no site
- [ ] abrir a rota principal anunciada em mobile
- [ ] abrir `/api/health`

## Funil

- [ ] verificar leads
- [ ] verificar custo por lead
- [ ] verificar cadastros
- [ ] verificar onboarding concluido
- [ ] verificar primeira resposta gerada
- [ ] verificar checkout iniciado
- [ ] verificar assinatura ativa
- [ ] verificar leads por `utm_source`
- [ ] verificar leads por `utm_campaign`

## Produto

- [ ] verificar feedbacks
- [ ] verificar bugs
- [ ] verificar geracao de IA
- [ ] verificar limite mensal
- [ ] verificar dashboard
- [ ] verificar pagina de assinatura
- [ ] verificar demo publica

## Tecnico

- [ ] verificar Vercel logs
- [ ] verificar Supabase
- [ ] verificar Stripe
- [ ] verificar Resend
- [ ] verificar OpenAI usage
- [ ] verificar GA4
- [ ] verificar Meta Pixel

## Decisao do dia

- [ ] manter campanha
- [ ] reduzir orcamento
- [ ] pausar
- [ ] trocar criativo
- [ ] ajustar landing
- [ ] corrigir bug
