# Roteiros de Video da Campanha Otimizada

Videos curtos para Reels, Stories ou criativo vertical. Nao mostrar dados reais de clientes.

## Roteiro 1: pergunta repetida

Tempo: 15 segundos.

1. Tela: caixa de texto generica com pergunta comum.
2. Fala: "Todo dia voce responde a mesma pergunta no WhatsApp?"
3. Tela: AtendeZap IA gerando sugestao.
4. Fala: "Digite o contexto do seu negocio e receba uma resposta para revisar."
5. Tela: botao de demo.
6. Fala: "Voce copia e envia manualmente. Teste gratis."

## Roteiro 2: delivery

Tempo: 20 segundos.

1. Tela: "Qual o prazo de entrega?"
2. Fala: "Delivery perde tempo com perguntas repetidas."
3. Tela: resposta sugerida com texto generico.
4. Fala: "O AtendeZap IA cria uma sugestao educada e pronta para adaptar."
5. Tela: CTA.
6. Fala: "Teste uma resposta para seu atendimento."

## Roteiro 3: estetica

Tempo: 20 segundos.

1. Tela: "Tem horario hoje?"
2. Fala: "Agenda cheia e WhatsApp acumulado?"
3. Tela: exemplo de resposta segura sobre disponibilidade.
4. Fala: "Gere mensagens para explicar proximos passos sem mandar nada automaticamente."
5. Tela: CTA.
6. Fala: "Veja uma resposta de exemplo."

## Checklist do criativo

- [ ] sem print de conversa real
- [ ] sem telefone, nome, email ou endereco
- [ ] sem promessa de envio automatico
- [ ] CTA aponta para link com UTM oficial
- [ ] texto legivel em mobile
