# Checklist diario da campanha inicial

Use durante a primeira campanha pequena. O objetivo e evitar gastar dinheiro sem saber onde o funil esta travando.

## Antes de olhar decisoes

- [ ] Verificar gasto do anuncio.
- [ ] Verificar visitantes no GA4/Meta.
- [ ] Verificar leads no admin.
- [ ] Verificar UTMs no relatorio de campanha.
- [ ] Verificar cadastros.
- [ ] Verificar onboardings concluidos.
- [ ] Verificar respostas geradas.
- [ ] Verificar checkouts iniciados.
- [ ] Verificar assinaturas ativas.
- [ ] Verificar feedbacks recebidos.
- [ ] Verificar feedbacks de dificuldade de uso.
- [ ] Verificar erros no Vercel.
- [ ] Verificar erros no Supabase.
- [ ] Verificar eventos Stripe.
- [ ] Verificar custo OpenAI.
- [ ] Anotar bugs encontrados.
- [ ] Decidir se mantem, pausa ou ajusta.

## Criterio rapido

Continuar quando existem leads, usuarios entendem o produto, concluem onboarding, geram respostas e aparece intencao de compra.

Ajustar quando leads chegam, mas cadastro, onboarding, primeira resposta ou checkout travam.

Pausar quando lead, IA, checkout, webhook, assinatura ou acesso quebram.
