# Roteiro de Teste Beta - AtendeZap IA

## Objetivo
Validar se uma pessoa consegue usar o AtendeZap IA sem ajuda.

## Passos para o usuario testar
1. Criar conta
2. Preencher onboarding
3. Gerar uma resposta
4. Copiar a resposta
5. Salvar a resposta
6. Abrir biblioteca
7. Usar um template
8. Avaliar a resposta
9. Enviar uma sugestao ou problema pelo suporte

## Perguntas para o usuario
- Voce entendeu para que serve o produto?
- Conseguiu gerar uma resposta?
- A resposta foi util?
- Alguma parte ficou confusa?
- Voce usaria isso no atendimento real?
- O que faltou para ficar melhor?
- Voce pagaria por isso? Por que?

## Observacoes
Nao pedir dados sensiveis, senhas ou dados de cartao.
