# Criterios de Entrada - Versao 1.1 AtendeZap IA

## Pode iniciar versao 1.1 quando

* MVP estavel
* nenhum P0 aberto
* P1 criticos corrigidos ou aceitos
* operacao controlada funcionando
* feedback real suficiente
* metricas minimas acompanhadas
* custos sob controle
* seguranca validada

## Nao iniciar versao 1.1 se

* login/cadastro instavel
* IA instavel
* Stripe instavel
* RLS com risco
* admin inseguro
* custos fora de controle
* suporte com muitos bugs criticos

## Possiveis focos da 1.1

* melhorar ativacao
* melhorar dashboard
* melhorar respostas por nicho
* melhorar templates
* melhorar relatorios
* melhorar pricing
* melhorar suporte
* melhorar metricas
